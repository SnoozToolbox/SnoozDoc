.. _Slow_wave_classifier:

=================================================
Classify Slow Waves
=================================================

This tool classifies the slow waves of a cohort into categories based on their transition frequency, and reports their characteristics per category.

The classifier uses the files generated by the tool :ref:`Slow_wave_detection`:

* **Slow wave characteristics files**: one file per recording, one row per slow wave event, with its transition frequency (column ``trans_freq_Hz``).
* **Slow wave cohort report**: one file for the cohort, one row per recording and channel, with the valid duration of the recording and of each sleep cycle (see :ref:`slow_wave_cohort_info_csv`).
* **Sleep stages files**: one file per recording, with the epochs of the sleep stages selected for the detection, inside the sleep cycles (listed as events).

.. warning::

   Check "Detailed report for the cohort" and "Characteristics of each slow wave" on step "4 - Output Files" of the :ref:`Slow_wave_detection` tool. The sleep stages files are written when both are checked.

The transition frequency of a slow wave is 1/(2τ), where τ is the time from its negative peak to its positive peak (Bouchard et al., 2021).


Steps
-----------------

**1 - Input Files**

Add the slow wave characteristics files, the slow wave cohort report, and the sleep stages files for your cohort.
The list of recordings to be processed is taken from the slow wave characteristics files.

.. note::

   The slow wave characteristics files are saved in a folder named "slow_wave_characteristics", next to the cohort report.

   The sleep stages files are saved in a folder named "slow_wave_sleep_stages", next to the cohort report.

Snooz finds the sleep stages file and the rows of the cohort report of each recording by its name: keep the names written by :ref:`Slow_wave_detection`.
For example, with slow wave events named ``sw_carrier``, ``learn-nsrr01_sw_carrier.tsv`` goes with ``learn-nsrr01_sw_carrier_stages.tsv`` and with the rows of ``learn-nsrr01`` in the cohort report.
The cohort report must hold the slow waves of a single event name.
Before the classification, Snooz checks the files and lists the missing ones.

**2 - Classification Criteria**

The transition frequencies of all the slow waves of all the files and channels are put together, and a Gaussian mixture is fitted to their distribution.
Each Gaussian component is a category of slow waves.
Each slow wave is then assigned to the closest category, with a k-means clustering started from the means of the components.
The categories are numbered by transition frequency: category 1 holds the slow waves with the slowest transitions.
The same categories are used for all the recordings of the cohort.

Two options are available:

1. **An automatic classification**

Gaussian mixtures of 1, 2, 3 and 4 components are fitted, and the mixture with the lowest Akaike Information Criterion (AIC) is kept.
In other words, the Gaussian mixture with the lowest AIC value determines the number of slow wave categories present in the dataset.
The AIC of each mixture is written in the log of the run.

2. **A manual classification**

Specify the number of slow wave categories to use (1 to 4).

.. note::

   Useful if the automatic classification doesn't analyze the dataset correctly, or if you already know how many slow wave categories there are in the set.
   For example, you can select an automatic classification for a group data analysis to find out the number of slow wave categories, then apply this number to each individual if an individual analysis is needed.

**3 - Output Files**

Choose the output folder for the output files.
Files with the same names in the output folder are replaced.

*Slow wave characteristics by event level*

Each slow wave is labeled with its category.
The slow wave characteristics files are copied to the output folder, under the same names, with the category of each slow wave in a new column ``category``. Choose a folder other than "slow_wave_characteristics" to keep the original files.
There is one slow wave characteristics file per PSG recording.

*Slow wave characteristics by subject level*

A cohort report (``sw_cohort_details_per_categories.tsv``) holds the slow wave characteristics averaged per category, one row per recording and channel.
For each category, it gives the number of slow waves, their density (slow waves per minute) and the average of their characteristics.
The slow wave characteristics are also given per sleep cycle and per segment of the night.

* Per sleep cycle, only the valid data is counted. The artifacts and the sleep stages not selected for the detection are excluded.
  The maximum number of sleep cycles is set in the optional settings "Hours and Cycles" of the step. Use at most the number of sleep cycles set in :ref:`Slow_wave_detection` (6 by default), since the slow wave cohort report has no values for the other cycles.
* Per segment of the night, the epochs of the sleep stages file of each recording (the sleep stages selected for the detection, inside the sleep cycles) are divided into equal parts, in time order.
  All these epochs are counted, artifacts included. The remaining epochs go to the first segments. For example, 501 epochs divided into 2 segments give a first half of 251 epochs and a second half of 250 epochs.

Choose the granularity of the segments. Select 2 to divide the night into halves, 3 for thirds, 4 for quarters, and so on.

A description file (``sw_cohort_details_per_categories_info.tsv``) gives the definition of each column of the cohort report.
In the cohort report, the segments of the night are named divisions (for example, ``cat1_div1_out3_sw_count`` is the number of slow waves of category 1 in the first third of the night).

*Classification model*

The distribution of the transition frequencies of the cohort is modeled with a Gaussian mixture.
The histogram of the transition frequencies, with the resulting model, is saved in the output folder as a .pdf picture (``SW_trans_freq_and_AIC_gaussian_fit_<n>_auto_categories.pdf``, else ``SW_trans_freq_hist_<n>_manual_categories.pdf``).
When the number of categories is found automatically (not set manually), the picture also shows the Akaike Information Criterion (AIC) for 1 to 4 categories.
